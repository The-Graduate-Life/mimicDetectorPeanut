# AI Use Disclosure

This project used Claude (Anthropic) as a coding and technical-writing assistant during pipeline debugging, methodological review, and documentation. This statement describes exactly what that involved.

## What the AI assisted with

**Debugging and code patches.** During execution of the vendored mimicDetector pipeline, Claude helped diagnose eight real defects — seven in the vendored `mimicDetector` codebase and one in this project's own figure-generation script — and authored the patch scripts that fix them (`scripts/patch_*.py`). The most significant of these (`patch_hpops_output_dir.py`) corrected a silent data-validity bug: an incorrect output-path construction that caused every host-side QSASA value to default to `NaN` for the entire run, without raising an error. Full description of each patch and its rationale: `FOLLOWME.md`, Section 16.

**Methodological review.** Claude identified that the originally implemented false discovery rate calculation (`scripts/06_calculate_fdr.py`) used a "unique peptide" definition that was mathematically degenerate given this pipeline's pre-deduplicated hit tables — it would return FDR = 1.0 regardless of the underlying data. Claude proposed and implemented a corrected definition (`scripts/06_calculate_fdr_v2.py`), documented as an explicit methodological interpretation in `report/final_report.md`, Section 7, since the source paper does not specify this at the level of detail needed to resolve it directly.

**Original scripts.** Claude wrote `scripts/build_decoy_hcfiltered.py` (replicates the pipeline's bitscore-difference filter against the decoy database) and `scripts/diagnose_lcr_evalue.py` (a read-only diagnostic for inspecting borderline candidates).

**Documentation.** Claude revised `README.md`, `FOLLOWME.md`, and `report/final_report.md`, and reviewed them for internal consistency, stale/placeholder content, and unsupported claims.

## What the AI did not do

- **No biological or computational results were generated by the AI.** All sequence data came from UniProt and AlphaFold DB; all BLASTP, POPScomp, and Snakemake computations were performed by the named tools, run by the researcher on the researcher's own infrastructure.
- **The AI did not have direct execution access to the research environment.** All commands were run by the researcher; the AI proposed commands and patch scripts, which were reviewed and executed independently.
- **All patches were verified against synthetic test cases** reproducing the relevant bug before being applied to the real codebase, and their effects were confirmed against real pipeline output afterward.
- **No scientific conclusion in this project was adopted without independent verification** by the researcher against the actual data and output files.

## Responsibility

The researcher reviewed all AI-assisted code changes, verified all reported numbers against real output files, made all methodological and scientific decisions (including which analyses to run, which to defer, and how to interpret results), and takes full responsibility for the accuracy and integrity of this work.
